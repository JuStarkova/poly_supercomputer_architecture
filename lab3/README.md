# Лабораторная работа № 3: параметры кеш-памяти

Три микробенчмарка на C++ измеряют задержку доступа к памяти при обходе цепочек указателей. По изменениям задержки можно оценить параметры кеша процессора:

- `cache_levels`: размеры уровней кеша при увеличении рабочего набора.
- `cache_line`: размер строки кеша при изменении расстояния между двумя узлами.
- `cache_assoc`: ассоциативность кеша L1 при увеличении числа узлов, попадающих в один набор.

## Сборка и запуск

Нужны Linux или WSL и `g++` с поддержкой C++17. Из корня репозитория:

```bash
cd lab3
mkdir -p build
g++ -std=c++17 -O2 program_code/cache_levels.cpp -o build/cache_levels
g++ -std=c++17 -O2 program_code/cache_line.cpp -o build/cache_line
g++ -std=c++17 -O2 program_code/cache_assoc.cpp -o build/cache_assoc

./build/cache_levels
./build/cache_line
./build/cache_assoc
```

Программы не требуют аргументов и выводят задержки в наносекундах на один переход. Результаты зависят от процессора и нагрузки системы; `cache_levels` обычно выполняется дольше остальных.
