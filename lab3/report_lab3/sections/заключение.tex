\section*{Заключение}
\addcontentsline{toc}{section}{Заключение}

Все программы были собраны компилятором \texttt{g++} с параметром \texttt{-O2} и запущены в WSL на процессоре AMD Ryzen 7 4800HS. Для исключения миграции между ядрами процессы были закреплены за логическим процессором 0. Для сравнения был использован вывод \texttt{lscpu -C}.

По изменению задержки доступа были получены оценки размеров кешей: 32~КиБ для L1d, 512~КиБ для L2 и 4~МиБ для L3. Размер строки был оценён в 64 байта, ассоциативность L1d --- в восемь строк на набор. Все оценки согласуются с данными \texttt{lscpu}.
