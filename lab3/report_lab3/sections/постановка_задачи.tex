\section*{Постановка задачи}
\addcontentsline{toc}{section}{Постановка задачи}

\textbf{Цель.} Косвенно определить параметры кеш-памяти процессора 
по результатам измерения времени доступа к данным.

\textbf{Задачи.}
\begin{enumerate}
    \item Оценить размеры кешей L1d, L2 и L3.
    \item Определить размер строки кеша.
    \item Оценить ассоциативность кеша данных первого уровня (L1d).
\end{enumerate}
